# docx-to-html
Converting .docx to .html

Exploring tools like BeautifulSoup or docx-parser-converter, may also attempt to convert from .docx to .pdf to .html, or .docx to .xml to .html.

Running Python 3.10.0

The script using docx_parser_converter is currently blocked and unable to correctly convert from .docx to .html

The script using Beautiful Soup is currently working and able to produce .html files. However, it is too lossy to be feasible (output .html file does not retain any text formatting or hierarchy). Will attempt to rewrite the script to make a smarter converter.
